# iNotebook 📝

iNotebook is a full-stack notes management web application that allows users to securely create, update, delete, and manage personal notes online.

## 🚀 Features

- User Authentication (Signup/Login)
- Create Notes
- Edit Notes
- Delete Notes
- Responsive UI
- Secure JWT Authentication
- MongoDB Database Integration

## 🛠️ Tech Stack

### Frontend
- React.js
- Bootstrap
- HTML/CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
